# COSA CAMBIA rispetto a quello online:
#
#  1. RIMOSSO il gruppo "User-agent: Googlebot-Image".
#     Un gruppo con nome sostituisce integralmente il gruppo * per quel crawler
#     (RFC 9309: vale un solo gruppo per bot). Googlebot-Image perdeva quindi tutte
#     le altre direttive. Ed era inutile: /wp-content/uploads/ è già in Allow.
#
#  2. RIMOSSO "User-agent: AdsBot / Disallow: /".
#     "AdsBot" non è un token valido di Google — i reali sono AdsBot-Google e
#     AdsBot-Google-Mobile. Se interpretato per prefisso può bloccare il controllo
#     di qualità delle landing di Google Ads.
#
#  3. AGGIUNTO "Disallow: /*?add-to-cart=".
#     [MISURATO] È il 12% dei 1.129 URL in "Non trovata (404)" di GSC: ~135 URL.
#     Non è un residuo storico — sono link che il sito emette adesso, quindi
#     continuerebbero a nascerne. Il blocco ferma il crawl; per chiudere la sorgente
#     serve anche rel="nofollow" sui pulsanti di aggiunta al carrello.
#
#  4. AGGIUNTO "Disallow: /*?remove_item=" e il blocco delle pagine transazionali.
#     [MISURATO] Nell'access log del 27/07 Googlebot ha eseguito
#       GET /carrello/?remove_item=6c91e2bfb5160ae267d4f353cf706f52&_wpnonce=... -> 200
#     Googlebot stava crawlando URL di modifica del carrello. Carrello, checkout,
#     account ed express-checkout non hanno alcun motivo di essere scansionati.
#
#  5. AGGIUNTE trappole di crawl: ?orderby, /feed/, /embed/.
#     NB: la paginazione /page/N/ NON è bloccata qui di proposito — va gestita lato
#     server con canonical o 404 (execution-kit/09-pagination-fix.md), così Google
#     può leggere il canonical invece di trovare l'URL semplicemente vietato.
#
#  6. TOLTA la riga "Sitemap: .../news-sitemap.xml": quella sitemap non esiste ancora.
#     Dichiarare una sitemap inesistente aggiunge solo rumore.
#
#  7. DA DECIDERE — crawler AI. Sotto è attiva l'opzione "testo aperto, immagini
#     protette" (§11.1): GPTBot / Google-Extended / CCBot possono leggere l'HTML ma
#     non /wp-content/uploads/. Motivo: i file ad alta risoluzione sono il prodotto,
#     il testo è marketing e rende il sito citabile dagli assistenti.
#     Costo misurato del blocco attuale: 2 sessioni/settimana da "AI Assistant" in GA4.
#     PER RI-BLOCCARE DEL TUTTO: sostituire, sotto ciascuno dei tre, le due righe
#     "Allow: /" + "Disallow: /wp-content/uploads/" con una sola "Disallow: /".
